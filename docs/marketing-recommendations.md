# Marketing recommendations draft

## First two weeks

1. Put studio headshots, weddings, portraits, and real estate in that order on the services page. Give each a direct booking or inquiry action.
2. Add the session length, deliverables, turnaround, and optional add-ons beside each booking action. Verify the current terms before publishing.
3. Test each path on a phone, from the landing page to the confirmation screen. Record completed inquiries and bookings by service and channel.
4. Ask recent customers for a review after delivery using the review link that fits the service.
5. Post a weekly example that answers one booking question. Start with headshot prep, wedding coverage, and portrait session timing.

## Review after two weeks

Compare counts of qualified inquiries, bookings, completed forms, and reviews by service. Keep channel attribution consistent. Current baselines and expected lift are unverified. Show **Not available yet** wherever tracking is missing.
